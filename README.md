# WorkFlow — Worker Transport

Updated prototype with:
- WorkFlow red/white branding and app icon
- Worker booking dashboard
- Admin dashboard for pricing, drivers and ride assignment
- Driver dashboard with assigned rides
- Google Maps address autocomplete and route distance when a restricted browser API key is configured
- Manual distance fallback if map services are unavailable
- Fare calculation using fuel price, 12 L/100 km vehicle consumption, operating cost, margin and minimum passenger fare

For a real multi-user production system, add secure authentication, a backend/database, server-side secrets, notifications and payment/compliance controls.
